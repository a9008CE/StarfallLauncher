Installation

三步开始，零门槛

STEP 01

下载启动器

点击「下载 Windows 版」，保存 QuartzLauncher-1.1.0.exe 到任意位置。

STEP 02

准备 Java 17+

首次启动会提示缺少 Java，点确定即可自动下载 Temurin 17；也可手动安装后指定路径。

推荐：Eclipse Temurin 17 ↗
STEP 03

开始游戏

选择版本与加载器，点启动。游戏文件、补丁与资源会自动补全。

FAQ

常见问题，快速解答

星落 LaunCher 支持哪些 Minecraft 版本？
支持从 1.0 到最新版本的几乎所有 Minecraft 版本，包括 Forge、Fabric、Quilt、NeoForge 等主流加载器。
启动器需要什么 Java 版本？
启动器本身需要 Java 17 或更高版本运行；Minecraft 的 Java 需求由启动器自动管理，不同版本的游戏会匹配对应的 Java。
如何离线游玩？
在设置中选择「离线模式」，输入游戏用户名即可。离线模式支持自定义皮肤库和 Steve / Alex 模型切换。
Mod 自动依赖解析是怎么工作的？
安装 Mod 时，启动器会自动扫描依赖列表，从 CurseForge 或 Modrinth 下载缺失的前置 Mod，无需手动逐个查找安装。
启动器会自动更新吗？
会。每次启动自动检查新版本，发现更新后后台下载，由新版直接完成替换并重启，不丢任何数据。
更新后启动器不见了怎么办？
更新过程会写入日志 Launcher/update-apply.log；新版启动成功后会自动清理旧版备份，如遇异常可检查日志排查。
支持 macOS 或 Linux 吗？
目前仅支持 Windows x64；macOS 与 Linux 支持已在计划中。
